# Numerical reference fixtures

`references/` contains independent numerical oracles for production shader paths. [`reference-fixtures.js`](reference-fixtures.js) defines the cases, dimensions, sample formulas, source hashes, and tolerances; [`reference-fixtures.json`](reference-fixtures.json) records the generated bytes and toolchain.

From a full source checkout, verify the committed fixtures offline:

```sh
npm run reference:check
```

Regeneration from a full source checkout requires Linux and the audited mpv, libplacebo, FFmpeg, Xvfb, Mesa, and software-OpenGL versions recorded in the manifest:

```sh
npm run reference:generate
npm run reference:check
```

The generator verifies pinned GLSL sources, creates 16-bit inputs, renders through mpv, and converts the exact-size screenshot to little-endian RGB16. It rejects shader failures and replaces output only after every case succeeds. Canonical fixture digests are independently pinned in `reference-fixtures.js`, so accepting a deliberate numerical change requires reviewing the rendered difference and updating both the digest and provenance.

FSRCNNX, SSimDownscaler, and adaptive sharpen run their pinned upstream GLSL. ArtCNN uses the shaders' own f32 fallback because Mesa cannot accept their repeated float16 feature-selection blocks after mpv shader injection; regeneration requires exactly eight deterministic replacements per model.

The model case uses structured grayscale at `37×23 → 74×46` to cover odd dimensions, partial workgroups, and padded borders. SSimDownscaler uses Catmull-Rom scaling at `62×38 → 31×19`; adaptive sharpen uses structured RGB at `37×23`. BT.709 extraction and recombination use CPU oracles because the extension intentionally applies a fixed matrix while mpv performs its own metadata-driven color management.

Pixels are tightly packed unsigned 16-bit little-endian `R`, `G`, `B` samples in top-to-bottom order. Score the entire frame. Model comparison uses reference red because nominally gray mpv screenshots can differ slightly between display channels. FSRCNNX and sharpen references clamp readback to the presentation range represented by their screenshots; production intermediates remain unclamped.
